# 代码

## controller

```java
@RestController
@RequestMapping("/follow")
public class FollowController {

    @Resource
    private IFollowService followService;

    /**
     * 关注用户
     * @param followUserId 关注用户的id
     * @param isFollow 是否已关注
     * @return
     */
    @PutMapping("/{id}/{isFollow}")
    public Result follow(@PathVariable("id") Long followUserId, @PathVariable Boolean isFollow){
        return followService.follow(followUserId, isFollow);
    }

    /**
     * 是否关注用户
     * @param followUserId 关注用户的id
     * @return
     */
    @GetMapping("/or/not/{id}")
    public Result isFollow(@PathVariable("id") Long followUserId){
        return followService.isFollow(followUserId);
    }
}
```

## service
```java
@Service
public class FollowServiceImpl extends ServiceImpl<FollowMapper, Follow> implements IFollowService {

    /**
     * 关注用户
     *
     * @param followUserId 关注用户的id
     * @param isFollow     是否已关注
     * @return
     */
    @Override
    public Result follow(Long followUserId, Boolean isFollow) {
        Long userId = ThreadLocalUtls.getUser().getId();
        if (isFollow) {
            // 用户为关注，则关注
            Follow follow = new Follow();
            follow.setUserId(userId);
            follow.setFollowUserId(followUserId);
            this.save(follow);
        } else {
            // 用户已关注，删除关注信息
            this.remove(new LambdaQueryWrapper<Follow>()
                    .eq(Follow::getUserId, userId)
                    .eq(Follow::getFollowUserId, followUserId));
        }
        return Result.ok();
    }

    /**
     * 是否关注用户
     *
     * @param followUserId 关注用户的id
     * @return
     */
    @Override
    public Result isFollow(Long followUserId) {
        Long userId = ThreadLocalUtls.getUser().getId();
        int count = this.count(new LambdaQueryWrapper<Follow>()
                .eq(Follow::getUserId, userId)
                .eq(Follow::getFollowUserId, followUserId));
        return Result.ok(count > 0);
    }
}

```




mybatisPlus

这段代码是 MyBatis-Plus 的**条件构造器（Wrapper）**用法，作用是根据指定条件删除数据，**不需要写 SQL**。

---

### 一、整段代码在做什么？

```java
this.remove(new LambdaQueryWrapper<Follow>()
        .eq(Follow::getUserId, userId)
        .eq(Follow::getFollowUserId, followUserId));
```

翻译成人话：

> 删除 `follow` 表中满足以下条件的记录：
> - `user_id = userId`
> - `follow_user_id = followUserId`

生成的 SQL 等价于：

```sql
DELETE FROM follow 
WHERE user_id = #{userId} 
  AND follow_user_id = #{followUserId}
```

---

### 二、逐部分拆解

#### 1. `this.remove(...)`

`remove` 来自 `ServiceImpl`，是 MyBatis-Plus 提供的删除方法。它接受一个 `Wrapper` 条件参数。

```java
// ServiceImpl 源码简化
public boolean remove(Wrapper<T> queryWrapper) {
    return baseMapper.delete(queryWrapper);
}
```

**不传条件会怎样？**

```java
this.remove(null);   // 删除整张表的所有数据！
```

所以传 `Wrapper` 是为了**指定删除哪些行**。

---

#### 2. `new LambdaQueryWrapper<Follow>()`

创建一个 **Lambda 条件构造器**，用来构建 WHERE 条件。

-   `QueryWrapper`：用字符串写列名，如 `.eq("user_id", userId)`
-   `LambdaQueryWrapper`：用 **Lambda 表达式**引用字段，如 `.eq(Follow::getUserId, userId)`

**Lambda 写法的好处**：字段名变了，编译期就会报错；字符串写法则要等到运行时才暴露。

---

#### 3. `.eq(Follow::getUserId, userId)`

-   `eq` = equal，即 `=`
-   `Follow::getUserId`：引用了 `Follow` 实体类的 `userId` 字段
-   `userId`：变量值

MyBatis-Plus 会自动把 `Follow::getUserId` 解析为数据库列名：

```
Follow::getUserId → userId → user_id
```

所以条件就是：`user_id = #{userId}`。

---

#### 4. 链式调用叠加条件

```java
.eq(Follow::getUserId, userId)
.eq(Follow::getFollowUserId, followUserId)
```

多个 `.eq` 之间默认是 **AND** 关系：

```sql
WHERE user_id = ? AND follow_user_id = ?
```

---

### 三、完整等价 SQL 和传统写法对比

#### MyBatis-Plus Lambda 写法：

```java
this.remove(new LambdaQueryWrapper<Follow>()
        .eq(Follow::getUserId, userId)
        .eq(Follow::getFollowUserId, followUserId));
```

#### 传统 MyBatis XML 写法：

```xml
<delete id="deleteFollow">
    DELETE FROM follow 
    WHERE user_id = #{userId} 
      AND follow_user_id = #{followUserId}
</delete>
```

```java
followMapper.deleteFollow(userId, followUserId);
```

两者效果完全一样，但 MyBatis-Plus 不需要写 XML。

### 四、条件构造器常见方法

| 方法 | 含义 | SQL 片段 |
|:---|:---|:---|
| `.eq(字段, 值)` | 等于 | `field = value` |
| `.ne(字段, 值)` | 不等于 | `field != value` |
| `.gt(字段, 值)` | 大于 | `field > value` |
| `.ge(字段, 值)` | 大于等于 | `field >= value` |
| `.lt(字段, 值)` | 小于 | `field < value` |
| `.le(字段, 值)` | 小于等于 | `field <= value` |
| `.like(字段, 值)` | 模糊查询 | `field LIKE '%value%'` |
| `.in(字段, 集合)` | 在集合中 | `field IN (...)` |
| `.isNull(字段)` | 为空 | `field IS NULL` |
| `.orderByDesc(字段)` | 降序排序 | `ORDER BY field DESC` |
| `.last("...")` | 追加自定义 SQL | `LIMIT 1` 等 |

### 五、实际使用场景（黑马点评关注功能）

这是**取消关注**的典型代码：

```java
public Result unfollow(Long followUserId) {
    Long userId = ThreadLocalUtls.getUser().getId();
    
    // 删除 follow 表中：我关注了 followUserId 的那条记录
    this.remove(new LambdaQueryWrapper<Follow>()
            .eq(Follow::getUserId, userId)
            .eq(Follow::getFollowUserId, followUserId));
    
    return Result.ok();
}
```

对应的表结构：

```sql
CREATE TABLE tb_follow (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,          -- 谁
    follow_user_id BIGINT    -- 关注了谁
);
```

执行后删掉的就是“我关注了你”这条关系记录。

### 六、总结

| 问题 | 答案 |
|:---|:---|
| `this.remove()` 是什么？ | MyBatis-Plus 的删除方法，来自 `ServiceImpl` |
| `LambdaQueryWrapper` 是什么？ | 用 Lambda 表达式构建 WHERE 条件的工具 |
| `.eq(A::getX, value)` 是什么？ | 添加一个 `x = value` 条件 |
| 多个 `.eq` 什么关系？ | AND |
| 最终效果？ | 按条件删除记录，不需要写 SQL |
