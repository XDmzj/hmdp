# 问题
![[Pasted image 20260804173926.png]]
项目部署在多台服务器上，负载均衡把请求分发到不同机器。

两个请求同时到达不同服务器：

- 服务器1的线程获取了synchronized锁，开始执行业务
    
- 服务器2的线程也获取了synchronized锁，也开始执行业务
    
- 两台服务器的锁完全独立，互不影响
    
- 结果：一人一单再次失效


**问题本质**：synchronized是JVM级别的锁，锁信息在各自进程的内存里，跨进程就管不到了。

**需要换一种锁**：需要一个所有服务器都能访问到的公共存储来存放锁信息。Redis就是常用的选择。
